KEY FEATURES FOR USERS
================================================================================

1. STRIKE TILL DAYS
   What: Strike tasks for 1-365 custom days instead of just Today or Forever
   Why: Lets users postpone tasks without permanent dismissal
   Benefit: Better task lifecycle management

2. REFRESH NOW
   What: Instantly unstrike temporarily struck tasks
   Why: Plans change - users need to restore tasks before snooze expires
   Benefit: More user control and flexibility

3. FIXED NOTE CONTENT DISPLAY
   What: Notes no longer show encoded blobs (__SHAKSHUKA_SPLIT_B64_V1__...)
   Why: Content was being saved as base64-encoded rather than readable text
   Benefit: All notes display correctly regardless of source

4. BETTER NOTE SEARCH
   What: Search "note 5" now finds "note-5" and "Note 5 Details"
   Why: Old search only worked with exact substring matching
   Benefit: Much more intuitive and flexible search

5. CLEAN MOBILE SYNC
   What: Only one modal appears when syncing, notes don't duplicate
   Why: Modal duplication was confusing, duplicate notes cluttered library
   Benefit: Cleaner UX and data integrity
