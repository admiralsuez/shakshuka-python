Shakshuka Task Manager - Portable Version
==========================================

This is a portable version of Shakshuka Task Manager that can run without installation.

HOW TO USE:
1. Double-click "Shakshuka.exe" to start the application
2. The app will open in your default browser at http://127.0.0.1:8989
3. Your data will be automatically saved to: %APPDATA%\Shakshuka\
4. Use the system tray icon for app management

FEATURES:
- Modern task management interface
- System tray integration
- Auto-save functionality
- Daily task resets
- Data backup system
- No installation required

SYSTEM REQUIREMENTS:
- Windows 10/11
- No additional software needed

DATA LOCATION:
Your tasks and settings are stored in:
%APPDATA%\Shakshuka\data\

This ensures the app works even when installed in Program Files without permission issues.

SUPPORT:
For issues or questions, check the documentation in the docs/ folder.
