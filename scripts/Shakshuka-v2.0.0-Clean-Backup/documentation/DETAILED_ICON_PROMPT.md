# 🎨 Ultra-Detailed Icon Design Prompt for Shakshuka

## 🎯 Master Prompt (Most Comprehensive)

### **For Midjourney v6**

```
/imagine prompt: Professional application icon for "Shakshuka" task management software. 
Design specifications: Modern rounded square app icon (1024x1024px), iOS/macOS style aesthetic. 

Visual composition: 
- Main element: Bold, dynamic checkmark symbol centered in frame
- Checkmark style: Thick stroke weight (15-20% of icon width), smooth flowing curves with subtle energy/motion implied through line weight variation
- Checkmark orientation: Slightly tilted 5-10 degrees right (suggesting forward momentum)
- Secondary element: Three subtle horizontal lines beneath/behind checkmark (representing task list items), progressively fading opacity (100%, 60%, 30%)

Color scheme (exact):
- Background: Rounded square with gradient, top-left to bottom-right
  - Start: #4DB6AC (Teal/Turquoise) 
  - End: #26A69A (Deeper Teal)
- Checkmark: Pure white (#FFFFFF) with 2px soft glow/halo effect
- Task lines: White with 40% opacity
- Corner radius: 20% of total size (iOS standard)

Lighting and depth:
- Very subtle inner shadow on background (2px, 10% opacity, suggests slight depth)
- Soft drop shadow on checkmark element (1px offset, 15% opacity)
- Overall feel: Flat design 2.0 (primarily flat with minimal depth cues)

Technical requirements:
- Vector-quality rendering
- High contrast for visibility at 16x16px scaling
- No text, no texture, pure geometric shapes
- Clean edges, perfect curves using bezier paths
- Suitable for both light and dark mode interfaces

Artistic direction:
- Style: Contemporary tech company aesthetic (think Notion, Linear, Figma quality)
- Mood: Confident, energetic, professional yet approachable
- Avoid: Overly corporate/boring, childish/playful, cluttered/complex
- Target: Modern productivity professionals, ages 25-45
- References: Award-winning app icons from Apple Design Awards

Quality markers:
- Pixel-perfect alignment on grid
- Mathematically precise curves and angles
- Professional gradient (subtle, not garish)
- Memorable silhouette even at small sizes
- Timeless design (won't look dated in 5 years)

Output format: Square canvas, centered icon with 10% padding margin, 
transparent or white background, ultra-high resolution (4K), 
suitable for conversion to .ico multi-resolution format

--v 6 --style raw --quality 2 --ar 1:1
```

## 🎨 Pro Tips for Best Results

### **Color Precision**
Use exact hex codes: `#4DB6AC` not "teal"
Specify gradients: "linear, 45°, from X to Y"
Consider color spaces: sRGB for web, P3 for quality

### **Size Specifications**
Always specify: "1024×1024px" not "large"
Request: "scalable to 16px" for usability
Ask for: "vector-quality" for crisp edges

### **Style Control**
- `--stylize 50`: Very literal, precise
- `--stylize 150`: Balanced artistic interpretation  
- `--stylize 500`: Creative, artistic freedom
- `--stylize 1000`: Maximum creativity

### **Quality Assurance**
- Always request: "pixel-perfect alignment"
- Specify: "no pixelation" or "crisp edges"
- Ask for: "professional quality" or "award-winning"
- Include: "suitable for conversion to .ico"

## 📐 Technical Reference

### **iOS Icon Specifications**
- Size: 1024×1024px
- Corner radius: 223.38px (21.85%)
- Margin: 10% breathing room
- Format: PNG-32 with alpha

### **Windows Icon Specifications**  
- Sizes: 16, 32, 48, 256px
- Format: .ico with embedded sizes
- Background: Can use transparency
- Corners: Can be sharp or rounded

### **Universal Best Practices**
- Design at 1024px, scale down
- Test at final size (16px)
- Use vector when possible
- Embed color profiles
- Optimize file size
