# 🎨 Icon Design Prompts for Shakshuka

## Application Overview
**Shakshuka** is a modern, professional task management and productivity application for Windows. It helps users organize tasks, track productivity, plan their day, and maintain focus with features like daily planners, analytics, and strike tracking.

---

## 📋 Detailed AI Prompt for Icon Generation

### **Primary Prompt (Recommended)**

```
Create a modern, professional application icon for "Shakshuka" - a productivity and task management app.

Design Requirements:
- Style: Clean, modern, minimal, professional
- Shape: App icon with rounded corners (iOS/macOS style or square with rounded edges)
- Primary concept: Blend of productivity symbols (checkmark, task list, clock) with energy/focus elements
- Color palette: Vibrant but professional - teal/turquoise (#4DB6AC), complemented with coral/orange (#FF7043) or deep blue (#1976D2)
- Background: Solid color or subtle gradient
- Icon should work well at small sizes (16x16px to 256x256px)
- Must be recognizable and memorable
- Convey: Organization, productivity, clarity, focus, modern workflow

Key elements to consider:
- A stylized checkmark or check-circle (task completion)
- Layered elements suggesting organization/stacking
- Subtle clock or time element (scheduling)
- Optional: Flame icon element (suggesting energy, "cooking up" productivity)
- Clean lines and high contrast for visibility

The icon should feel:
- Trustworthy and professional (for business use)
- Energetic and motivating (for personal productivity)
- Modern and tech-forward
- Easy to spot in a taskbar or app launcher

Output: Square icon, multiple sizes, transparent background or solid color background
```

## 📐 Technical Specifications

### **Required Sizes:**
- 16x16 px (Browser favicon, small icons)
- 32x32 px (Standard desktop icon)
- 48x48 px (Large icons view)
- 128x128 px (High DPI displays)
- 256x256 px (High resolution, scalable)

### **File Format:**
- Primary: `.ico` file with multiple sizes embedded
- Alternative: `.png` files that can be converted to .ico

### **Design Guidelines:**
1. **Visibility**: Must be recognizable at 16x16px
2. **Contrast**: High contrast for accessibility
3. **Simplicity**: Clean, not cluttered
4. **Uniqueness**: Distinctive from other task apps
5. **Scalability**: Looks good from tiny to large
6. **Flat or subtle depth**: No heavy 3D effects

## 🎯 Final Recommendations

### **For Shakshuka Specifically:**

**Best Approach**: Since "Shakshuka" is a Mediterranean dish (eggs in tomato sauce), consider:

1. **Direct Productivity Focus**: Clean checkmark or task list (most users won't know the food reference)
2. **Blend Both Worlds**: Organic, warm colors (teal/coral) with productivity symbols
3. **Abstract Energy**: Flame or sun shape that doubles as productivity "heat"

**My Top Pick Prompt**:
```
Create a modern app icon for Shakshuka task manager:

Design: A stylized checkmark inside a rounded square
- The checkmark has a flowing, energetic line (suggesting momentum)
- Background: Gradient from warm teal (#4DB6AC) to slightly deeper teal (#26A69A)
- Checkmark: Pure white (#FFFFFF) with subtle glow
- Rounded corners (20% radius)
- Flat design with one subtle shadow for depth
- Clean, professional, immediately recognizable

Style: Modern, professional, friendly
Sizes: Scalable from 16px to 256px
Format: Vector-style, high contrast, works in light/dark modes

The icon should feel like the perfect blend of "getting things done" and 
"energized productivity" - clean enough for corporate use, warm enough for personal use.
```
