## 🚀 Quick Change (3 Steps)

### **Step 1**: Get Your New Icon
Use AI prompt from `documentation/ICON_DESIGN_PROMPT.md`

### **Step 2**: Run Change Script
```powershell
.\scripts\change-icon.ps1 -NewIconPath "C:\path\to\your\new-icon.ico"
```

### **Step 3**: Rebuild
```powershell
python scripts\build.py
```
