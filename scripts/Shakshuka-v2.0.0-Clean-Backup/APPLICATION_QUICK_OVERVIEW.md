# 🍳 Shakshuka - Quick Overview

## What Is It?
A modern, privacy-focused Windows desktop task management app that runs entirely on your local machine.

## ⚡ Key Features (Top 10)

1. **📝 Task Management** - Create, organize, and track tasks with priorities, due dates, categories, and tags
2. **📅 Daily Planner** - Time-block your day with drag-and-drop hourly scheduling
3. **📊 Analytics** - Visualize productivity with charts and statistics
4. **🔥 Strike Tracking** - Build habits with daily completion streak gamification
5. **🎨 Themes** - 8+ color themes including self-esteem and anxiety modes
6. **📥 Import/Export** - Import from CSV/TXT, export to multiple formats
7. **🔒 Privacy-First** - All data stored locally, no cloud, no tracking
8. **⚡ Lightning Fast** - <3s startup, 50ms search, works offline
9. **🎯 Smart Filters** - Filter by status, priority, date, category, tags
10. **💾 Auto-save** - Never lose data with 30s auto-save + weekly backups
